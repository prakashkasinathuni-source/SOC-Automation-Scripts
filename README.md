# SOC Automation Scripts

This folder contains Python-based SOC automation scripts designed to assist in security operations tasks such as IOC analysis and log parsing.

---

## Purpose

These scripts simulate real-world SOC analyst automation tasks including:

- IOC reputation checking
- IP and domain analysis
- Log parsing
- Brute force detection
- Basic threat intelligence enrichment

---

## Scripts Included

### 1. IOC Checker
- Checks IP geolocation
- Basic domain resolution check
- Flags suspicious locations

### 2. Log Parser
- Parses authentication logs
- Detects failed login spikes
- Identifies possible brute force attacks
